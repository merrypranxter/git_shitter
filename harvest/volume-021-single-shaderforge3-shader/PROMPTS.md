## 01 — Style Pack Color Quantization Halos

**BASIS:** The Style Pack system allows loading custom palettes. This prompt speculates on using a palette's limited color set to drive a halo effect, where colors bleed and interact.

**IMAGE / IMPLEMENTATION PROMPT:**

Generate a GLSL fragment shader that visualizes halos originating from points on a grid. The color of each halo is determined by sampling a user-defined palette (loaded via Style Pack). The halo's size, intensity, and falloff are modulated by the luminance of the sampled color and a global 'dispersion' parameter. The effect should simulate chromatic aberration where colors from the palette's nearest neighbors in RGB space slightly misalign. Implement performance optimizations to ensure smooth animation, potentially by pre-calculating halo falloff curves or using texture lookups for color palettes. Test by loading diverse palettes and observing how color limitations create distinct halo patterns and chromatic fringe behaviors.

**WHY IT'S WEIRD:** It links the abstract concept of a color palette to a physical optical phenomenon (halos, chromatic aberration) and ties it to the generative system's core feature (Style Packs), creating a feedback loop between aesthetic choice and visual artifact.

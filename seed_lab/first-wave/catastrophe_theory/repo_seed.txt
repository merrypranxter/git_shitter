## Math spine: potentials and equilibria
For a cusp catastrophe use a 1D potential V(x;a,b) = x^4/4 + a*x²/2 + b*x. Equilibria satisfy dV/dx = x³ + a*x + b = 0. The discriminant is Δ = -4a³-27b². Crossing Δ=0 changes root multiplicity and typically the number of real equilibria. Stable equilibria of gradient dynamics `dx/dt = -dV/dx` correspond to local minima of V (d²V/dx²>0).
For fold use V=x³/3 - a*x (stationary x²=a). This simple local model is not a bounded physical potential; keep visualization in a finite region.
Swallowtail and butterfly are higher-codimension families. Show their genuine control parameter structure rather than claiming any random ripple is a catastrophe.

## Render pipeline
1. Numerically sample potential/gradient and locate equilibria via root-bracketing + optional refinement.
2. Display stable and unstable branches distinctly.
3. Sweep one or two controls with slow interpolation to demonstrate hysteresis **only** when a dynamics/branch-following rule supports it.
4. Convert equilibrium branches and discriminant curves into SVG paths and contour fills.
5. Optional second-stage creative *mapping*: branch count drives SDF lobes, fold amplitudes, membrane segmentation, or particle emissions. Label this a visual metaphor, not the underlying theorem.

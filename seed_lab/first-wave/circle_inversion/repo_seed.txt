# circle_inversion — REPO SEED
Status: SPECIFICATION ONLY. A new source repo does not exist yet.

## The Goldmine
Use actual circle inversion as a visual operator: a perfectly ordinary family of lines, circles, glyphs or growth networks becomes an alien ornamental geometry under a single mathematical mapping. This is a sibling to, not a duplicate of, `apollonian_gasket`: the primary product is a reusable arbitrary-geometry inversion engine with controllable singularity handling and SVG export.

## Mathematical spine
Choose inversion center c=(cx,cy), radius R>0. For a point p != c, let q=p-c. The inverted point is p' = c + (R²/||q||²)q. Inversion fixes points on its circle; points very near c are sent very far away. Generalized circles behave as follows: a circle not through c maps to another circle, a circle through c maps to a line, and a line not through c maps to a circle through c.

Do **not** describe this as a conformal mapping at the inversion center; it is undefined there and orientation-reversing away from it. A naive straight segment endpoint transform is wrong because inverted segments are generally arcs.

## Implementation strategy
- Core `invertPoint(p, center, radius, epsilon)`: return explicit missing/unbounded status for ||p-c||<epsilon rather than pretending it is finite.
- Curves: sample polylines adaptively in source space with refinement driven by curvature after inversion; clip to finite export viewport.
- Closed outlines: preserve subpath breaks and fill rules; inverted polygons may require arc tessellation to prevent false straight edges.
- Optional analytical circle/line transforms for high-quality vectors and fewer points.
- Multi-center composition: apply inversions in a user-defined ordered sequence; never imply it is commutative.
- Show poles/singularities, prevent NaN/Infinity in SVG, preserve reproducible seeds.

## Output contracts / quality gates
Export standalone white-background black-fill SVG for dingbats, optional transparent PNG, and mathematically intact SVG strokes. Tests: fixed points on inversion circle; involution (invert twice recovers p within tolerance); center singularity is handled; numerical output has no NaN; circles-through-center map to a line.

## Build order / closing directive
Implement and test point inversion first. Add adaptive path sampling, simple SVG exporter, then interactive viewport and presets. The first win is a single seed producing 9 genuinely different black-on-white, individually separable ornamental shapes without manually tracing raster output. No paid inference in the render loop.
